# ShoeShop — учебная система магазина обуви

Учебный проект: спроектировать и создать систему для магазина обуви. Покупатель сможет смотреть каталог и оформлять заказ, а сотрудники — управлять товарами и заказами.

> **Статус:** подготовка проекта. Описание функций и метрик — черновик; уточним его с преподавателем и командой.
>
> **Подтверждено:** C#, настольное приложение, работа в Visual Studio.
>
> **Предложение, если преподаватель не задавал детали:** Windows Forms + SQLite — простой вариант для учебного приложения.

## Участники команды

- Газизов Кирилл
- Яковлев Данил

## Цель

Сделать систему, в которой покупатель может найти обувь и оформить заказ, а сотрудник магазина — поддерживать каталог и остатки в актуальном состоянии.

## Что планируем сделать

- каталог обуви с карточками товаров, поиском и фильтрами;
- вход в систему и разные права для покупателей и сотрудников;
- добавление, просмотр, изменение и удаление товаров;
- корзину и заказы со статусами;
- учебную имитацию оплаты;
- журнал действий и проверку работы системы.

## Границы проекта

- Настоящие платежи через банк подключать не планируем — оплата будет учебной имитацией.
- Курьерскую доставку и отдельное мобильное приложение в проект не включаем.
