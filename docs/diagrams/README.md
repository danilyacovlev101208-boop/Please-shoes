# Блок-схемы «Воздух»

Диаграммы подготовлены по тексту задания модулей 1–3 и памятке по draw.io. Основной поток идёт сверху вниз; линии и подписи чёрные, фон белый. Соединители ортогональные: выходят из центра нижней границы блока и входят в центр верхней границы следующего.

| Файл | Функция |
|---|---|
| `1.png` / `1.drawio` | D01 — импорт исходных данных |
| `2.png` / `2.drawio` | D02 — запуск приложения и подключение к БД |
| `3.png` / `3.drawio` | D03 — вход гостя и авторизация по роли |
| `4.png` / `4.drawio` | D04 — навигация и проверка прав |
| `5.png` / `5.drawio` | D05 — вывод каталога и оформление карточек |
| `6.png` / `6.drawio` | D06 — поиск, фильтр поставщика и сортировка |
| `7.png` / `7.drawio` | D07 — открытие формы товара |
| `8.png` / `8.drawio` | D08 — проверка и сохранение товара |
| `9.png` / `9.drawio` | D09 — добавление или замена фото |
| `10.png` / `10.drawio` | D10 — безопасное удаление товара |
| `11.png` / `11.drawio` | D11 — сообщения об ошибке, предупреждении и результате |
| `вся-программа.png` / `вся-программа.drawio` | Общий поток работы приложения |

Файлы `.drawio` — редактируемые исходники; PNG — экспортированные изображения.
